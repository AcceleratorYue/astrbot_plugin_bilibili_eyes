## 0. 实现状态（2026-11-04）

v0.12.0 已实现只读 MVP：

- `pages/pluginCenter`：概览、视频记录、视频详情、原文检索、缓存管理、诊断、配置摘要；
- `plugin_api`：概览/视频/详情/原文/缓存/配置/诊断路由；
- 视频详情四个标签：核心笔记、其他客观内容、帧预算、原文；
- 缓存支持按类型清理；
- 配置只读，SESSDATA 脱敏；
- 页面通过 AstrBot 插件页桥接，无独立服务。

后续扩展：真删除确认、缓存过期筛选、更多配置白名单编辑、SQLite 历史检索。

## 1. 定位

WebUI 不是聊天客户端，也不是配置页的替代品，而是 B站之眼的**管理、查看和排障面板**：

1. 看插件当前状态和最近观看记录；
2. 查看每次观看的笔记、帧预算、ASR/字幕状态；
3. 直接浏览/检索字幕和 ASR 原文；
4. 清理笔记/原文/帧缓存；
5. 只读查看配置，少量安全配置可编辑；
6. 诊断模式选择、ASR、Provider、缓存和失败原因。

核心原则：

> 配置页负责“改参数”，WebUI 负责“看结果”；两者不重复堆功能。

## 2. 参考 AstrBot 插件页机制

`astrbot_plugin_get_px` 的做法：

```text
pages/pluginCenter/
  _page.json
  index.html
  app.js
  styles.css
plugin_api/
  api.py
```

- `_page.json` 定义页面标题和描述；
- `pages/pluginCenter` 是插件页面静态资源；
- `plugin_api/api.py` 用 Quart 注册 `GET/POST` 路由；
- 前端通过 `window.AstrBotPluginPage` 与 AstrBot 页面桥接；
- 页面由 AstrBot 插件管理入口打开，不依赖单独 Web 服务。

B站之眼建议沿用这一形态，不额外启动服务、不占用端口。

## 3. 页面结构

### 3.1 总体布局

```text
┌────────────────────────────────────────────────────────────┐
│ B站之眼 · 观看与笔记管理          [刷新] [返回插件列表]   │
├──────────────┬─────────────────────────────────────────────┤
│ 概览         │  当前页面内容                               │
│ 视频记录     │                                             │
│ 原文检索     │                                             │
│ 缓存管理     │                                             │
│ 诊断         │                                             │
│ 设置         │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

左侧导航固定，右侧内容区宽度自适应；窄屏改为顶部标签。

### 3.2 概览

卡片：

- 插件状态：启用/禁用、当前 `video_mode`；
- 最近一次观看：BV、标题、模式、耗时、帧数/图片数；
- 缓存：笔记条数、原文条数、帧目录大小；
- ASR：开关、Provider、最近状态；
- 异常：最近 24 小时警告数量。

不展示 Cookie/API Key，只展示“已配置/未配置”。

### 3.3 视频记录

表格列：

| 列 | 内容 |
| --- | --- |
| 时间 | 最近观看时间 |
| 标题 | 视频标题 |
| BV / 分P | bvid + page |
| 模式 | normal / enhanced / extreme |
| 帧数 | 实际帧数 / 目标帧数 |
| 笔记 | 核心字数 / 其他字数 |
| 文本 | 官方字幕 / ASR / mixed / none |
| 状态 | 成功 / 部分 / 失败 |

操作：

- 点击进入详情；
- 按模式、BV、标题搜索；
- 分页；
- 删除单条笔记/原文/帧缓存。

### 3.4 视频详情

Tab：

1. **核心笔记**：Markdown 渲染，显示故事梗概/连续叙事/关键对白/关键画面/不确定项；
2. **其他客观内容**：元数据、评论区原文、关键弹幕；
3. **原文**：官方字幕 / ASR 分栏，支持关键词、时间范围、来源过滤；
4. **帧预算**：时长、基础帧数、文本/画面画像、目标/实际帧数、每张格数、证据缺口；
5. **诊断**：ASR 状态、字幕状态、缓存路径、警告、耗时。

原文 Tab 的查询结果直接复用 `bilibili_transcript` 后端逻辑，不在前端做二次总结。

### 3.5 原文检索

全局检索页：

```text
关键词 [____]  时间 [__:__] - [__:__]
来源 [both ▼]  最多 [20 ▼]
[搜索]
```

结果行：

```text
[00:12] 官方字幕：……
[00:14] ASR（约）：……
```

支持：

- 点击时间跳转视频详情（不内嵌播放器，只显示时间点）；
- 复制单行/多行；
- 显示来源和状态；
- 无结果/缓存缺失时明确提示。

### 3.6 缓存管理

按类型：

- 笔记缓存（NoteCache）；
- 原文缓存（TranscriptStore）；
- 帧/拼图缓存。

操作：

- 查看条数、大小、最旧/最新；
- 按视频删除；
- 按过期时间清理；
- 清空某一类；
- 二次确认，防止误删。

不提供“下载原视频”或“导出 Cookie”。

### 3.7 诊断

展示：

- 当前模式与配置摘要；
- 最近失败：类型、时间、BV、脱敏错误；
- ASR：Provider、状态、最近一次分块数/耗时；
- 字幕：官方/absent/failed；
- 帧计划：目标/实际/上限/缺口；
- 缓存命中/未命中。

提供：

- “复制脱敏诊断信息”按钮；
- 不展示完整日志、Cookie、API Key、评论原文。

### 3.8 设置

只读展示分组配置；

可编辑白名单（需管理员）：

- `video_mode`；
- `extreme_max_frames` / `extreme_max_sheets` / `extreme_readability`；
- `digest_max_chars` / `enhanced_digest_max_chars`；
- `audio_transcription_enabled` / `mode`；
- `cache_ttl_hours` / `transcript_ttl_hours`；
- 等待提示开关。

不建议在 WebUI 编辑：

- SESSDATA；
- 完整提示词模板；
- 第三方投稿 API；
- 复杂切点参数。

这些继续放配置页，避免 WebUI 成为第二套配置系统。

## 4. 后端 API 设计

建议新增：

```text
plugin_api/api.py
```

路由：

### 4.1 概览

```text
GET /overview
```

返回：

```json
{
  "version": "0.11.0",
  "enabled": true,
  "video_mode": "extreme",
  "last_video": {"bvid": "...", "title": "...", "mode": "extreme", "created": 0},
  "notes": {"count": 0, "bytes": 0},
  "transcripts": {"count": 0, "bytes": 0},
  "frames": {"count": 0, "bytes": 0},
  "asr": {"enabled": true, "status": "available"},
  "warnings": 0
}
```

### 4.2 视频列表/详情

```text
GET /videos?q=&mode=&limit=50&offset=0
GET /videos/{bvid}/{page}
GET /videos/{bvid}/{page}/notes
GET /videos/{bvid}/{page}/transcript?query=&start=&end=&source=&limit=
```

详情返回：

```json
{
  "video": {"bvid": "...", "page": 1, "title": "..."},
  "mode": "extreme",
  "frame_plan": {},
  "note_lengths": {"core": 0, "other": 0},
  "status": {"official": "available", "asr": "available"},
  "warnings": []
}
```

原文查询直接调用现有 `TranscriptStore.search()` / `format_result()` 的纯函数，避免前端重复实现。

### 4.3 缓存

```text
GET /cache/summary
POST /cache/cleanup
```

请求：

```json
{"kind": "notes|transcripts|frames|all", "bvid": "", "page": 0, "expired_only": true}
```

### 4.4 配置

```text
GET /config
POST /config
```

- GET 只返回白名单字段，SESSDATA 等脱敏为 `"***"` 或 `"已配置"`；
- POST 只允许白名单字段，服务端校验类型/范围；
- 写配置后刷新内存配置，不要求重启。

### 4.5 诊断

```text
GET /diagnostics
POST /diagnostics/stt-test
```

`stt-test` 只做轻量可用性检查，不上传用户录音；如果没有测试素材，返回“不可测试”。

## 5. 前端设计

### 5.1 技术形态

建议第一版不使用构建工具：

```text
pages/pluginCenter/
  _page.json
  index.html
  app.js
  styles.css
```

- 原生 HTML/CSS/JS；
- 无 npm 构建；
- 与 get_px 一样通过 AstrBot 页面桥接；
- 若后续复杂，再迁移到 Vue/React。

### 5.2 视觉

- 深色为默认，跟随 AstrBot 主题；
- 左侧导航 + 内容卡片；
- 表格行高适中，长标题省略；
- 状态色：
  - 成功：绿色；
  - 部分/警告：黄色；
  - 失败：红色；
  - 无数据：灰色。

### 5.3 关键交互

- 页面加载：骨架屏；
- 空状态：说明“还没有看过视频”/“原文缓存为空”；
- 错误：显示脱敏错误 + 重试；
- 删除：二次确认；
- 搜索：300ms 防抖；
- 请求超时：显示重试，不无限转圈。

## 6. 数据来源

| 数据 | 来源 |
| --- | --- |
| 视频记录 | `NoteCache` 文件 + `_session_materials`（运行期） |
| 笔记内容 | `NoteCache` JSON |
| 原文 | `TranscriptStore` JSON |
| 帧预算 | 笔记 JSON 中的 `frame_plan`（需补充保存） |
| 帧文件 | `data/frames/{bvid}` 目录 |
| 运行状态 | 插件内存 `Job`/最近任务 |
| 配置 | AstrBot plugin config |

当前 `NoteCache` 只保存 digest，不保存 frame_plan/status。WebUI 第一版可先只读笔记和原文；要展示帧预算，需要让 `NoteCache.set(meta=...)` 保存更多元数据。

## 7. 安全与权限

1. **管理员页面**：写操作只允许管理员；
2. **脱敏**：SESSDATA、API Key、Cookie 永不返回；
3. **路径限制**：只访问插件 data 目录，拒绝任意路径；
4. **BV 校验**：只接受 `BV...` 格式；
5. **日志**：不返回完整日志，只返回脱敏摘要；
6. **CSRF/鉴权**：依赖 AstrBot 插件页面桥接的会话；
7. **删除操作**：二次确认，服务端再次校验 scope；
8. **原文隐私**：原文只在本机 data 目录，不跨群展示；
9. **不提供**：远程下载、任意文件读取、Cookie 导出。

## 8. 实施阶段

### Phase 0：设计冻结

- 评审本文档；
- 确认只读/可写字段；
- 确认页面入口与权限。

### Phase 1：只读后端

- `/overview`、`/videos`、`/videos/{bvid}/{page}`、`/notes`、`/transcript`；
- 不写配置、不删除缓存。

### Phase 2：只读前端

- 页面壳、概览、视频表、详情、原文检索；
- 空状态/错误/加载。

### Phase 3：缓存管理

- 缓存统计与清理；
- 二次确认。

### Phase 4：配置白名单

- 只读配置展示；
- 少量安全字段编辑；
- 服务端校验。

### Phase 5：诊断与权限

- 诊断信息；
- 管理员权限；
- 安全测试。

## 9. 非目标

- 不做聊天客户端；
- 不内嵌视频播放器；
- 不替代 AstrBot 配置页；
- 不提供 B站账号登录；
- 不导出 Cookie/SESSDATA；
- 不跨群查看原文；
- 不自动重新下载/ASR。

## 10. 总结

建议先做只读 WebUI，再接缓存清理和少量配置编辑：

```text
AstrBot 配置页：参数分组 + 修改
B站之眼 WebUI：观看记录 + 笔记 + 原文 + 缓存 + 诊断
```

配置页的 10 个分组已经落地；WebUI 第一版只需要读现有 NoteCache/TranscriptStore，不必改动取帧/笔记主流程。

本设计不实现 WebUI；后续按 Phase 1~5 单独评审。
